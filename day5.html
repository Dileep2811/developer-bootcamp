How Event Handling Works in this App

1. Event Listeners (addEventListener)

Instead of using inline HTML attributes like onclick="...", we bind events in JavaScript using element.addEventListener(type, callback). This keeps our markup clean and allows binding multiple actions to the same trigger.

form.addEventListener('submit', handleFormSubmit);

2. Preventing Default Behavior (event.preventDefault())

When a form is submitted, the browser's default behavior is to reload the page or navigate to a target. By calling e.preventDefault() in our submit callback, we stop this refresh and allow JavaScript to process the inputs client-side without interrupts.

e.preventDefault(); // Inside submit handler

3. Event Delegation

Instead of adding click handlers to every edit and delete button individually (which is inefficient and fails for newly created dynamic cards), we attach a single listener to the parent container (#records-list). By reading e.target, we can determine exactly which child was clicked.

container.addEventListener('click', (e) => { ... });
